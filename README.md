## How to Run Locally

1. Open the project folder.
2. Double-click `index.html`, or open it in a browser.
3. To browse the full site, use the navigation menu at the top of the page.

## Beginner Notes

- Update the business name, phone number, email, and location in the HTML files.
- Replace the sample SVG images in `assets/images/` with real project photos later.
- Save your business logo as `assets/images/logo.png` so the header uses the real brand image.
- The contact form is front-end only for now. You can connect it to a service later.

## Deployment Options

You can deploy this website later using:

- GitHub Pages
- Netlify
- Vercel
- Shared hosting with cPanel

## Simple Deployment Guide

### GitHub Pages

1. Create a GitHub repository.
2. Upload all project files.
3. Push the files to the `main` branch.
4. In the repository settings, enable GitHub Pages.
5. Select the root folder as the source.

### Netlify

1. Create a Netlify account.
2. Drag the project folder into Netlify Drop, or connect a Git repository.
3. Publish the site.

### Vercel

1. Create a Vercel account.
2. Import the project.
3. Deploy with the default settings.
